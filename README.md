# CS Projects

Games and game engines I've written while learning.

## Highlights

- **[Chispita](microstudio/chispita)** is a 2D game engine for [microStudio](https://microstudio.dev), written in microScript. It covers sprites, physics, collisions, tile maps, a camera, timers, tweens and a debug mode, and it comes with [full documentation](microstudio/chispita/CHISPITA_DOCS.txt).
- **[Chispita for LÖVE](love2d/chispita)** is a port of Chispita to [LÖVE](https://love2d.org) in Lua, with the same functions, settings and behavior.
- **[Shmup](microstudio/shmup)** is a ship game in progress, built on Chispita. Its flight model takes each ship's mass and drag from the ship's shape, and the pilot can get out and walk around. [▶ Play it](https://microstudio.io/Sjamescalaway/day1thegameplayloopdrawing/JE4B894V/)
